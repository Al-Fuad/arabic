# Vocabulary illustration generation

Mode: built-in imagegen (not CLI/API fallback).

`word-jobs.json` records the exact prompt, Arabic spelling, Bengali meaning,
source-page metadata when available, and intended output filename for each
additional illustration. Final images live in `public/images/words/`.
Existing illustrated vocabulary keeps the original `vocabulary-3d.webp` artwork.

These are supplemental learning illustrations, not reproductions or additional
claims of source-book coverage. Function words and abstract concepts use visual
metaphors; the Arabic word and Bengali meaning remain the authoritative labels.

The interactive companion is `public/images/companion-hudhud.png`. It provides
local study tips and reactions, not an AI conversation service.
