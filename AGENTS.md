# Project workflow

The user manages Vercel. Publish changes ONLY by committing and pushing to the existing GitHub origin. Do not create, update, or deploy Vercel projects or change domains. The GitHub integration deploys pushes automatically.

# Course content

Use native web lessons and interactive exercises, never scanned PDF page embeds as the lesson UI. The source scope is Esho-Arbi-Shikhi.pdf, PDF viewer pages 15–102 inclusive, first volume. Preserve source-page references on vocabulary, examples and rules. Do not equate an OCR extraction or a page having an entry with exhaustive coverage. Review Arabic and Bengali against source images before asserting complete coverage. Keep the content audit honest.
